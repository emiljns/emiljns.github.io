# 🌐 emiljns.github.io

My personal website built with HTML, Tailwind CSS, and JavaScript, nothing fancy.

It includes:
- Animated intro card UI
- Contact form that sends messages to Discord via webhook
- Live Spotify status using Lanyard WebSocket
- Dynamic background based on currently playing song

## 🚀 Live Site
https://emiljns.github.io

## 🛠 Tech Stack
- HTML
- Tailwind CSS (CDN)
- Vanilla JavaScript
- WebSockets (Lanyard API)
- Discord Webhooks

## ✨ Features
- Click to reveal info card
- Contact form with validation
- Real time Spotify presence
- Smooth background transitions
- Peely as background

## 📁 Files
- `index.html` – main page layout
- `style.css` – custom styles/animations
- `script.js` – UI logic/WebSocket handling
- `constant.js` – config values

## ⚠️ Security Note
Webhook URLs should never be exposed publicly.  
In production, this should be handled via a serverless proxy.
